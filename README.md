# ALLinAI# 五子棋人机对抗游戏

一个基于 Vue 3 + TypeScript 的现代化五子棋游戏，支持人类玩家与智能AI对战。

## ✨ 特性

- 🎮 **完整的游戏体验**：标准19×19棋盘，完整的五子棋规则
- 🤖 **智能AI对手**：基于极小极大算法和Alpha-Beta剪枝的AI引擎
- 🎨 **精美界面**：现代化UI设计，流畅的动画效果
- 🔊 **音效系统**：丰富的游戏音效和视觉特效
- ⚙️ **多种配置**：可调节AI难度、棋盘大小、时间限制等
- 📱 **响应式设计**：支持桌面端、平板和手机设备
- 🧪 **高质量代码**：完整的测试覆盖，TypeScript类型安全

## 🎯 游戏规则

1. **目标**：在19×19的棋盘上，率先连成5子的一方获胜
2. **落子**：玩家（黑子）和AI（白子）轮流落子
3. **获胜条件**：横、竖、斜任意方向连成5子即获胜
4. **平局**：当棋盘填满且无人获胜时为平局

## 🤖 AI系统

### 算法特点

- **极小极大算法**：经典的博弈树搜索算法
- **Alpha-Beta剪枝**：大幅提升搜索效率
- **启发式评估**：智能的局面评估函数
- **棋型识别**：识别各种攻防棋型

### 难度等级

| 难度 | 搜索深度 | 特点 |
|------|----------|------|
| 简单 | 2层 | 适合初学者，AI会出现明显失误 |
| 中等 | 4层 | 平衡的对手，有一定挑战性 |
| 困难 | 6层 | 高水平AI，很少出现失误 |
| 专家 | 8层 | 最高难度，提供最大挑战 |

## 🏗️ 技术架构

### 前端技术栈

- **Vue 3**：使用 Composition API
- **TypeScript**：类型安全的开发体验
- **Pinia**：现代化状态管理
- **Vite**：快速构建工具
- **Vitest**：单元测试框架

### 项目结构

```
src/
├── components/          # Vue组件
│   ├── ChessBoard/     # 棋盘相关组件
│   ├── ControlPanel/   # 控制面板组件
│   └── GameInfo/       # 游戏信息组件
├── stores/             # Pinia状态管理
├── types/              # TypeScript类型定义
├── utils/              # 工具函数
│   ├── gameLogic.ts    # 游戏逻辑
│   ├── aiEngine.ts     # AI引擎
│   ├── aiEvaluator.ts  # AI评估器
│   ├── audioManager.ts # 音频管理
│   └── effectsManager.ts # 特效管理
├── assets/             # 静态资源
└── __tests__/          # 测试文件
```

### 核心模块

#### 游戏逻辑 (`GameLogic`)
- 棋盘状态管理
- 落子验证
- 胜负判断
- 游戏规则实现

#### AI引擎 (`AIEngine`)

#### AI评估器 (`AIEvaluator`)

## 🔧 开发指南

### 添加新功能

1. 在 `types/` 中定义相关类型
2. 在 `utils/` 中实现核心逻辑
3. 创建对应的Vue组件
4. 编写测试用例
5. 更新文档

### 代码规范

- 使用 ESLint 进行代码检查
- 遵循 Vue 3 和 TypeScript 最佳实践
- 组件采用 Composition API
- 使用 TypeScript 严格模式
